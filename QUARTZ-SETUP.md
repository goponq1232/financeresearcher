# Quartz setup for Finance Research Garden

This repository now contains a Quartz-ready `content/` folder.

To publish it with Quartz:

1. Create a repository from the official Quartz template:
   https://github.com/jackyzha0/quartz/generate
2. Name it `finance-research-garden`.
3. Copy this repository's `content/` folder into that Quartz repository.
4. Follow the official Quartz GitHub Pages deployment guide:
   https://quartz.jzhao.xyz/hosting
5. Set the Quartz site title to **Finance Research Garden**.
6. Publish with GitHub Pages.

The notes already use Quartz-compatible wikilinks and Markdown.
